# 已有视频与字幕接管

管理员登录网站，打开 **媒体库 → 扫描与导入 → 扫描已有资源**。检查预览中的目录、状态和跳过项，再点击 **确认导入索引**。刷新页面后，资源仍保存在本地 SQLite；普通用户不会获得全库或磁盘路径访问权限。

扫描不移动、改名或写入媒体文件，不访问下载器、TMDB 或模型服务。确认导入会写 SQLite，并将唯一、已确认的下载文件/整理文件硬链接登记到 `media_link`。没有 TMDB 身份的文件显示“待识别”，不开放字幕处理按钮。导入不会创建下载任务或接管旧 qBittorrent 任务。

## 配置与目录

本地 Compose 将 `.env` 中 `MEDIA_DATA_DIR` 的**宿主机目录**挂载到容器 `/data`。例如 `MEDIA_DATA_DIR=./data` 实际使用项目下的 `data/`，不会使用宿主机 `/data`。如果真实媒体位于宿主机 `/data`，应使用 `MEDIA_DATA_DIR=/data`，并通过项目唯一 Docker 入口 `sh setup.sh local` 应用部署配置。

扫描发生在本地控制端，使用容器中可见的路径：

```dotenv
MEDIA_DOWNLOAD_ROOT=/data/downloads
MEDIA_LIBRARY_ROOT=/data/media_hub
```

两个目录必须存在、可读、互不包含。使用同一父目录挂载，才能保留硬链接能力。SQLite 保存在本地状态目录，不能放到媒体网络共享上。网站云端不扫描自己的文件系统。

新版功能涉及 local 控制端和 cloud 网页静态资源；分离部署需分别通过 `sh setup.sh local` / `sh setup.sh cloud` 重建更新。

将测试部署切换到真实目录或状态库前，先遵循 [正式接管方案](production-cutover-plan.md)，确认旧写入服务已退出，保留数据库备份；不能让两套媒体写入者同时管理同一目录。网页扫描入口不改变现有部署配置。

## 扫描状态

| 状态 | 含义与处理 |
| --- | --- |
| 已确认硬链接 | 唯一的一组文件具有相同设备号及 inode，可登记映射 |
| 已有映射 | 现有映射两端的实际文件身份一致 |
| 待整理 | 下载目录有视频，未找到整理目录中的硬链接；先保存索引，后续需识别和整理 |
| 仅有整理文件 | 整理目录有视频，未发现下载端关系；保留文件和索引，不虚构源路径 |
| 源文件缺失 / 整理文件缺失 | 有原映射，配置目录中的一端不存在；保留剩余文件，不自动补链 |
| 两端均缺失 | 原映射两端均不在当前扫描结果中；保留历史，不能由索引恢复字节 |
| 文件关系冲突 / 多个关联待核对 | 记录两端不是同一文件，或硬链接候选不唯一；不覆盖已有映射 |
| 路径不在当前目录范围 | 旧映射引用了当前配置范围外的路径；不读取这些路径，也不据此更新原映射为缺失 |
| 映射包含跳过的文件 | 旧映射包含符号链接或未支持的文件类型；不将未扫描到的文件误标为缺失 |
| 字幕已匹配 / 字幕待匹配 | 仅按同目录视频的完整文件名前缀关联外挂字幕，最长匹配优先；不推断语言、翻译或内容质量 |

磁盘索引保存在 `media_inventory`，扫描预览保存在 `media_mcp_record` 的 `inventory_scan` 记录中。独立资源和字幕无需伪造下载任务或源/目标映射，就能持久化和显示。主媒体库会显示已登记视频目标旁的字幕为“已发现 · 未校验”；已有字幕处理记录仍优先使用。

硬链接没有主从关系。删除下载端的路径后，只要整理端文件仍在，视频内容就还在。扫描不尝试追踪目录外的其他硬链接。

## 确认与失败恢复

空扫描会明确显示 0 项和宿主机媒体目录，并隐藏确认导入按钮；后端也拒绝空导入，不会将原有索引替换为空结果。`MEDIA_DATA_DIR=./data` 与 `MEDIA_DATA_DIR=/data` 是不同的宿主机目录，不能只根据容器内路径判断挂载是否正确。

非空导入返回实际写入的索引数量和新建映射数量，并将回执保存在扫描记录中；资源列表显示数据库中的实际总数及入库时间。只有独立文件、尚无确认映射时，管理员主媒体库也展示已保存的磁盘资源。

- 预览有效期为 30 分钟。确认导入前重新扫描核对文件指纹、目录配置和原映射；变化后要求重新扫描，不应用旧预览。
- 导入使用媒体操作锁和单个 SQLite 事务。丢锁或写入失败时回滚；重复确认同一预览不会重复建记录。
- 每次扫描最多遍历 20,000 个目录项，扫描循环限时 25 秒。超过上限或读取失败，不生成可导入的部分结果；可调整配置缩小扫描范围后重新扫描。慢磁盘的单次系统调用可能超出循环计时，HTTP 超时也不会触发导入。
- 不跟随符号链接；断链和特殊文件记录为跳过项。视频识别范围见 `storage/inventory.py` 的 `VIDEO`；外挂字幕范围见 `SUBTITLE`。扫描不解析容器内嵌字幕、不计算全视频哈希，也不自动识别 TMDB 身份。
- 已导入资源页展示最近一次完整导入的结果；旧扫描和索引记录仍保留。它是一次扫描快照，不是实时文件监视器，目录变化后需重新扫描确认。
- 本功能不是 MySQL→SQLite 迁移工具。旧库中的 TMDB 元数据、历史字幕处理和其他历史信息仍应按正式迁移流程导入。

## 隔离验收

使用临时 SQLite 和一次性下载/整理目录运行 `tests/test_inventory.py`。浏览器验收启动 `tests/manual/preview_platform.py`，只访问回环端口 `18293`；该服务创建虚构文件、用户和数据源，不连接下载器或启动 worker。

```sh
PYTHONPATH=src nice -n 15 python3 tests/manual/preview_platform.py
# 在另一个终端中，使用已安装的 Playwright 与 Chromium：
PLAYWRIGHT_MODULE=/path/to/playwright-core CHROME_EXECUTABLE=/path/to/chrome \
  nice -n 15 node tests/manual/acceptance_inventory_browser.cjs
```

截图与浏览器验收结果默认写入 `/tmp/media-ui-acceptance/`，可用 `MEDIA_BROWSER_ARTIFACTS` 更改。脚本仅使用预览服务的虚构账号。

浏览器复现空目录时，使用 `MEDIA_PREVIEW_EMPTY=true` 启动预览服务，并以 `MEDIA_BROWSER_EMPTY=true` 运行同一个浏览器脚本；验证“0 项”、没有确认按钮和后端拒绝空导入。另可用 `MEDIA_PREVIEW_NO_LINKS=true` / `MEDIA_BROWSER_NO_LINKS=true` 验证没有硬链接时，导入后刷新主媒体库仍可看到已保存资源。所有这些开关只用于一次性预览服务。
