编号。通过既有云端 provider 按这 65 个编号查询，65 个都有官方海报，无错误。
这属于展示资料缺失，不代表映射或字幕失败，不能通过重跑 AI 身份识别解决。

媒体库现在复用 `/api/detail`，按已知编号异步补图；未知合集不猜测、不搜索匹配。

源文件，不使用模型。详情读取有独立 metadata 预算 120 次/分钟、并发 2，避免
加载海报占用原有搜索预算；搜索、提交、AI 的额度规则不变。

专用搜索页面布局。
