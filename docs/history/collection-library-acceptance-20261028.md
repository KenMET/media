文件列表改为作品合集，后端先鉴权、聚合再分页；手机两列海报，详情按季集和版本展开。支持整部、整季、所选文件的身份确认、映射预览与修复、字幕维护。识别资料在 cloud 获取，NAS 保存 SQLite 索引与身份基线并执行维护任务。
